# Changelog

## v2.9.80 (2026-06-23)
- Оживлены слайдеры прозрачности и blur досок в «Стиле» (были мертвы из-за `:root !important` поверх inline). Слайдер управляет, только когда его трогали — дефолтный вид не изменился. Проверено CDP-рендером.

## v2.9.79 (ночная доработка 2026-06-23)

### Синхронизация закладок Chrome → доски (баг: закладки периодически не появлялись)
- Доски синхронизируются с папками Chrome на ВСЕХ страницах (раньше — только активная)
- Страховочный ресинк при возврате фокуса/видимости вкладки — ловит закладки, добавленные пока newtab был закрыт или в фоне
- Симметричный onRemoved с фолбэком по названию папки; защита от двойной привязки слушателей

### Надёжная Google-синхронизация (между устройствами)
- local-first: мгновенная запись в локальное хранилище + отложенная (дебаунс) в облако Chrome — убран молчаливый сброс в локальный фолбэк при частых сохранениях (drag/слайдеры)
- Живой приём изменений с другого устройства (chrome.storage.onChanged) с подавлением собственного эха
- Честный статус синхронизации в welcome-окне и настройках (подключено / недоступно / проверка)

### Импорт закладок из других браузеров
- Парсер файла закладок .html (формат Netscape: Firefox, Edge, Opera, Safari, Chrome)
- Кнопка «Импорт из файла браузера» в диалоге импорта и в настройках; переиспользует выбор папок
- Доски из файла не привязываются к папкам Chrome (без перекрёстного заражения); защита от битых файлов

### Онбординг и анимации
- Welcome-окно первого запуска: импорт Chrome / импорт из файла / чистый лист + статус синхронизации
- Анимации как опция (тумблер в настройках, уважает системную «уменьшить движение»): появление досок со stagger, плавное открытие окон, тосты

### Качество
- Два прохода адверсариального код-ревью агентами (устранена 21 находка, включая баги синхронизации)
- 55 юнит-проверок логики на реальном коде; проверка UI headless-рендером
