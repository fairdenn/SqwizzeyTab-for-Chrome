# Changelog

## v2.9.76 (current)
- Кнопка страницы (Home): в покое текст по центру кнопки, при наведении плавно
  уезжает влево, иконка-карандаш появляется справа с разделителем — без «дёрга»
- Текст подписи опущен на ~1.5px (вертикальное выравнивание)
- Иконка показывается только по hover / открытому меню (убрано залипание после клика)
- Вся геометрия кнопки сведена в один мастер-блок в конце styles.css
  (перекрывает ~80 наслоённых правил page-pill от старых версий; цвета/темы не тронуты)

## v2.9.75 (current)
- Точечное обновление: новая закладка добавляется в доску без перерисовки всей сетки (без мигания/прыжков)
- refreshBoardLinks() обновляет только список ссылок одной доски
- Полная синхронизация тоже обновляет только изменённые доски

## v2.9.74 (current)
- Синхронизация закладок Chrome: папка = доска
- Новые закладки (Ctrl+D) автоматически попадают в соответствующую доску
- Живой слушатель chrome.bookmarks.onCreated/onRemoved пока вкладка открыта
- Доски запоминают bookmarkFolderId при импорте
- Матчинг по ID папки, для старых импортов — фолбэк по названию

## v2.9.73 (current)
- 4 колонки досок всегда, round-robin раскладка
- DOM-based drag-and-drop досок между колонками
- Кнопка «+ Добавить доску» в каждой колонке
- Кнопка страницы: текст по центру, карандаш появляется при hover без прыжков
- Нейтрализованы конфликтующие старые drag-обработчики

## v2.9.51
