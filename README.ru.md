## Как это работает

1. **Открой новую вкладку** — закладки показываются досками в четыре колонки поверх обоев.
2. **Раскладывай перетаскиванием** — двигай ссылки между досками и доски между колонками; страницы группируют доски по контексту.
3. **Держи в синхроне** — доски вживую отражают папки закладок Chrome, а настройки синхронизируются между устройствами через аккаунт Google.
4. **Настрой под себя** — тема, обои, прозрачность и blur досок в панели стиля, с живым превью.

## Возможности

- Несколько страниц, на каждой — доски закладок в стабильной раскладке из четырёх колонок
- Drag-and-drop ссылок между досками и досок между колонками
- **Живая синхронизация закладок Chrome** — папка = доска; новые закладки (Ctrl+D) сами попадают в нужную доску
- Синхронизация настроек между устройствами через аккаунт Google (local-first + отложенная запись в облако)
- Импорт закладок из Chrome или из выгруженного `.html` другого браузера (Firefox, Edge, Opera, Safari)
- Тёмная и светлая темы, обои (встроенные или свои через IndexedDB)
- Настройка прозрачности и blur досок, акцентный цвет, анимации как опция (уважает «уменьшить движение»)
- Корзина с восстановлением 30 дней · экспорт/импорт JSON · undo-тост после удаления
- **Лёгкий режим** — отключает размытие фона ради экономии GPU и батареи

## Установка

Расширение распространяется как распакованная сборка (в магазине его нет):

1. Открой `chrome://extensions` и включи **Режим разработчика**.
2. Нажми **Загрузить распакованное расширение** и выбери папку этого репозитория.
3. Открой новую вкладку — Sqwizzey Tab её заменит.

Работает в Chrome и Brave. В Chrome 137+ флаг командной строки `--load-extension` ограничен — загружай через страницу расширений, как выше.

## Разработка

Vanilla JS/CSS/HTML без сборщика — правь файлы и перезагружай расширение:

```
newtab.html / newtab.js   :: страница новой вкладки и её логика
styles.css                :: все стили (один файл)
shared.js                 :: хранилище и синхронизация, общие с popup
popup.html / popup.js     :: popup на панели инструментов
manifest.json             :: манифест MV3 (здесь бампается версия)
```

После правок нажми иконку перезагрузки на карточке расширения в `chrome://extensions`. Правила дизайна проекта (кнопки, центрирование, скроллбары) — в [DESIGN.md](DESIGN.md), история версий — в [CHANGELOG.md](CHANGELOG.md).
