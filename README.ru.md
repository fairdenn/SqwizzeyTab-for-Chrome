<h1 align="center">Sqwizzey Tab</h1>

<p align="center">
  Замена новой вкладки для Chrome - визуальный менеджер закладок с досками, страницами, drag-and-drop и живой синхронизацией с папками закладок Chrome.
  <br>
  <a href="README.md">English</a> · <b>Русский</b>
</p>

## Как это работает

1. **Открой новую вкладку** - вместо пустой страницы закладки показываются досками. Папка закладок Chrome = доска.
2. **Раскладывай перетаскиванием** - двигай доски между колонками и ссылки между досками; всё сохраняется само и синхронизируется через твой аккаунт Chrome.
3. **Настрой под себя** - тема, обои и акцентный цвет; акцент подбирается из обоев автоматически или задаётся вручную.

## Возможности

- **Доски** - каждая папка закладок Chrome становится доской; всегда раскладка в 4 колонки (round-robin)
- **Страницы** - отдельные пространства (работа, учёба, личное), у каждого свои доски
- **Drag-and-drop** - сортировка ссылок внутри доски и перенос досок между колонками
- **Живая синхронизация с Chrome** - новые закладки (Ctrl+D) сами попадают в нужную доску, пока вкладка открыта
- **Импорт** - из папок Chrome или из файла закладок браузера `.html` (Firefox, Edge, Opera, Safari, Chrome)
- **Темы** - тёмная / светлая, встроенные обои или своё изображение, затемнение фона, свой акцентный цвет
- **Корзина** - восстановление удалённых досок, ссылок и страниц 30 дней; тост «Отменить» сразу после удаления
- **Поиск** - мгновенный, по закладкам, доскам и страницам
- **Светлая тема** интерфейса, опциональные анимации (уважают «уменьшить движение»), компактный режим, лёгкий режим (без размытия)
- **Экспорт / импорт** всей раскладки одним JSON-файлом
- Данные хранятся локально и синхронизируются через `chrome.storage.sync`

## Установка

В Chrome Web Store пока нет. Чтобы запустить распакованное расширение:

1. Склонируй или скачай репозиторий.
2. Открой `chrome://extensions` и включи **Режим разработчика** (справа вверху).
3. Нажми **Загрузить распакованное расширение** и выбери папку проекта.
4. Открой новую вкладку.
